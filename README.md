# 🛒 Superstore Sales & Profitability Optimization

An exploratory data analysis (EDA) pipeline designed to identify negative-margin items, assess regional profitability, and eliminate margin drag in retail transaction records.

## 📌 Business Problem & Impact
- **Margin Drag:** Identified that excessive discounting (>30%) on furniture items like Tables and Bookcases caused severe negative profit margins.
- **Actionable Solution:** Recommended capping promotional discounts at 20%, unlocking an estimated **~12% potential margin recovery**.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** VS Code, Git

## 📊 Visualizations & Findings
- Sub-categories like Tables and Bookcases showed consistent net losses.
- High discounts (>35%) directly correlated with unprofitable transactions.
